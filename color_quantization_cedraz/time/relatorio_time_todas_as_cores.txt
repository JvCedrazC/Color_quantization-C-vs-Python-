4. CAMPOS COMUNS

Todas as seis execuções terminaram com status 0, sem swaps, mensagens de
socket ou sinais entregues. A página do sistema tem 4.096 bytes. Os campos de
tamanho médio compartilhado, dados não compartilhados, pilha, tamanho total e
RSS médio foram registrados como zero pelo GNU Time.

Todas as execuções registraram zero blocos de entrada, pois a imagem já estava
no cache de página. As saídas foram gravadas em /tmp durante a medição; por
isso o GNU Time também registrou zero blocos de saída.

5. ANÁLISE

O wall clock cresceu de 0,80 s com 4 cores para 0,88 s com 128 cores. O tempo
interno da quantização cresceu de 0,757553446 s para 0,852458227 s, diferença
de 0,094904781 s (aproximadamente 12,53%). O uso de CPU entre 99% e 100%
confirma execução essencialmente limitada a um núcleo lógico.

Cada paleta foi medida uma vez. Os valores servem para comparar esta rodada,
mas uma conclusão estatística exigiria várias repetições por configuração.
